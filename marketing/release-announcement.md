# DashEChartsX 0.2.0 is out

## LinkedIn

DashEChartsX 0.2.0 brings accessible theming, chart export, and binary data
transport to Apache ECharts in Plotly Dash.

Highlights:

- Register named custom themes and add accessible labels and ARIA descriptions.
- Export rendered charts as PNG or SVG.
- Serve NumPy arrays as binary resources for large ECharts-GL datasets.
- Explore a searchable gallery of runnable Dash chart examples.

Install or upgrade:

```console
pip install dash-echartsx
```

For binary NumPy datasets, install the optional extra:

```console
pip install "dash-echartsx[binary]"
```

Explore the examples: https://huggingface.co/spaces/ravikrsh/Dash-App-Gallery

Documentation: https://rakrsh.github.io/dash-echartsx/v0.2.0/

Source and release notes: https://github.com/rakrsh/dash-echartsx/releases

## Plotly Community Forum

**Title:** DashEChartsX 0.2.0 — accessible charts, export, and binary data

Hi everyone,

We have released **DashEChartsX 0.2.0**, a Python component for using Apache
ECharts charts in Plotly Dash. This release adds named custom themes and
accessibility descriptions, PNG/SVG chart export, legend-toggle actions, and
binary transport for NumPy-backed ECharts-GL datasets. The interactive example
gallery also makes it easier to explore chart configurations alongside the
Python code that creates them.

The release is additive; existing chart options and callbacks continue to work.
NumPy is optional and is only needed for the binary dataset API:

```console
pip install dash-echartsx
pip install "dash-echartsx[binary]"
```
