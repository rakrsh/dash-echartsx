Migration from ``dash-echarts``
===============================

The migration guide covers the published ``dash-echarts`` 0.0.12.9 API,
including property changes, callback updates, map registration, and the
replacement for legacy JavaScript function props.

`Read MIGRATION.md on GitHub <https://github.com/rakrsh/dash-echartsx/blob/main/MIGRATION.md>`_.

Runnable examples are available in the :doc:`examples` gallery.
